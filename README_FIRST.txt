UNITY VERSION
Unity 6000.3.27f2 (Unity 6.3 LTS)

MAIN SCENE
Assets/Scenes/GolfCourse01.unity

OPENING THE PROJECT
1. Clone or download this repository.
2. Open the project folder in Unity Hub.
3. Use Unity Editor 6000.3.27f2.
4. Allow Unity to finish importing assets.
5. Open Assets/Scenes/GolfCourse01.unity.
6. Check the Console, then press Play to test the game.

PROJECT CONTENTS
- Assets — scenes, scripts, materials, models, textures, and other game assets
- Packages — Unity package configuration
- ProjectSettings — Unity project and editor settings
- README.md — current project documentation
- POCKET_PUTT_MODIFICATIONS.txt — notes about earlier source modifications

CURRENT STATUS
The project contains ten themed courses. The responsive course selector includes a compact COURSES menu on narrow/portrait screens. The current WebGL build is published at:
https://pocket-putt-arena.vercel.app

The Unity source repository and the deployed WebGL website are maintained separately. Build WebGL from Unity before publishing an updated browser version.
